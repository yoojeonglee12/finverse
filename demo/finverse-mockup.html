내 것만 하이라이트한 세계

유일하게 상호작용하는 화면. 계산은 결정론적 곱셈이고, LLM은 최대 2회만 쓴다.

1

내 종목 → 소속 섹터 → 연결 매크로
2
내 포트폴리오 영향 — 곱셈식 그대로 노출

2차전지 −3 × 0.20 = −0.60

합계 = −1.75

3
대가 4인 참고 — 참고·엔터 요소
버핏 · 관망달리오 · 균형 캐시 우드 · 매수막스 · 경계
실존 인물의 실제 발언이 아니며, 공개된 투자 원칙을 학습해 재구성한 교육용 시뮬레이션입니다.

공통 컴포넌트

컴포넌트규칙
안전·면책 레이어전 화면 공통. 페르소나 면책 라벨 상시 · 교육용 고지 · 상품 추천 금지
차트 색빨강 = 상승/촉진 · 파랑 = 하락/억제 (한국 시장 관례)
전망 표기단일 수치 금지 → 범위(rangePct). 3경로는 diverging
관계 강도강/중/약 3단계 질적 값. 0.73 같은 근거 없는 정밀 수치 금지
엣지 인코딩색 = sign · 굵기 = strength · 점선 = regulates
LLM 호출 예산 — 하루 무거운 생성 = BaseModel 1회 + 이벤트 카드 3~5회. 유저 경로는 세션당 ≤2회(편향 분류 · 결과 요약)이고, 캐시 히트 시 0회. 이 예산을 넘기는 설계가 나오면 그건 구조가 틀린 것이다.
안전 원칙 (전 화면 강제)
· 가격·수익·시장 방향 단정 금지 → 조건부 범위 + 신뢰구간으로만 표기
· 실계좌 연동 없음 — 전부 가상 프로필
· 상품 추천 금지 — 특정 종목 매매 권유로 읽힐 문구 금지
· 대가 페르소나 면책 라벨 상시 — 실존 인물의 실제 발언이 아님을 항상 명시
이 목업에서 아직 못 정한 것 (8/1 안건)
· 이벤트 카드 선별 기준 — 하루 몇 개 · 무엇을 매크로 관련으로 볼 것인가 (A-3)
· 트윈 템플릿 포트폴리오 3종 구성 (A-4)
· "왜 그렇게 판단했나" 입력 포함 여부 (B-2)
· 간접 경로(2-hop) 전파 규칙 — WTI → CPI → 소비재를 섹터 충격에 반영할 것인가 (C-3)
· 경량 시뮬 생성 시간 → V2 진행 UX의 목표 SLO (C-1)
